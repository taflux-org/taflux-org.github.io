# taflux – Landingpage

Statische Landingpage für [taflux.ch](https://taflux.ch), ausgeliefert über GitHub Pages.

- `index.html` – die Seite
- `style.css` – Gestaltung inkl. Hell-/Dunkelmodus
- `main.js` – Umschalter Hell/Dunkel und Release-Hinweis (ab 30.11.2026 wird die Ankündigung automatisch zum Link)
- `fonts/` – Newsreader und Hanken Grotesk, lokal eingebunden (SIL Open Font License)

Kein Build-Schritt: Dateien ändern, committen, pushen – GitHub Pages veröffentlicht automatisch.

Lokal ansehen: `python3 -m http.server` im Ordner starten und http://localhost:8000 öffnen.
